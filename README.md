## 🚀 Project Details

### Domain
Civil Aviation (US Domestic Flights). The system tracks flight schedules, departure/arrival logistics, and detailed delay causes (Weather, Carrier, Security, NAS).

### Data Source
* **Source:** Bureau of Transportation Statistics (BTS) / Kaggle
* **Dataset:** [Flight Data 2024](https://www.kaggle.com/datasets/hrishitpatil/flight-data-2024)
* **Volume:** ~1 Million Rows (Normalized into 10 Tables)

### Database Schema
The system uses a **Snowflake Schema** structure to ensure 3NF (Third Normal Form):
* **Fact Table:** `Flights`
* **Dimensions:** `Airports`, `Cities`, `States`, `Carriers`, `Calendar`
* **Details:** `Flight_Timings`, `Flight_Operations`, `Delay_Stats`, `Cancellations`
